# Resultados

Resultados do modelo em `weights/best.pt`, gerados pelo notebook de treino e por `src/avaliar.py`:

- `metricas.md`: métricas no conjunto de teste, gerais e por classe
- `results.png` e `results.csv`: curvas de loss e de mAP por época (validação)
- `confusion_matrix.png`: matriz de confusão no conjunto de teste
- `amostras_treino.jpg`: imagens de treino com as anotações
- `exemplos/`: imagens de teste com as bounding boxes previstas

O README da raiz explica os números e as ressalvas sobre o conjunto de teste.
