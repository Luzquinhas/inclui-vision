# Resultados

Esta pasta é preenchida pelo notebook de treino e por `src/avaliar.py`:

- `results.png` e `results.csv`: curvas de loss e de mAP por época
- `metricas.md`, `metricas.json`, `metricas_por_classe.csv`: métricas no conjunto de teste
- `confusion_matrix.png` e as curvas de precisão e recall
- `comparacao.csv`: uma linha por modelo avaliado
- `amostras_treino.jpg`: imagens de treino com as anotações
- `exemplos/`: imagens de teste com as bounding boxes previstas
